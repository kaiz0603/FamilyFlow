
# FamilyFlow (Java + Fragments + NavController)
最小可运行骨架，包含：
- 家庭编号生成/校验（SharedPreferences）
- 问卷保存（SharedPreferences）
- 个性化/普通内容切换（读取问卷偏好）

**导入方式 A（推荐）**：Android Studio -> Open -> 选择解压目录 `FamilyFlow` -> 等待 Gradle 同步 -> 运行。
若提示 Gradle Wrapper 缺失，Android Studio 会自动生成；或者你可以新建空项目后，将本项目的 `app/` 替换你的 `app/`。

目标 SDK: 35，最小 24。
